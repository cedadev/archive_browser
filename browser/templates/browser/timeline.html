Temporal coverage

The dates covered by a dataset can often be identified from its file names or directory structure. For example, a path such as /badc/ds/data/2014/04/29/... clearly contains a date, and a filename like .../fesa_20250910_yx.dat includes a date encoded as a number.

This plot is created by detecting dates within file paths and filenames and counting how many files correspond to each date. While this approach is not completely accurate, it provides a useful indication of the temporal coverage of many datasets.
